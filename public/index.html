Configuración y Canales Móviles

Instalar en tu Celular (PWA)

Esta aplicación funciona como una app nativa en Android y iPhone, con pantalla completa, icono de inicio y acceso ultrarrápido:

  • Android (Chrome): Toca el menú de tres puntos ⋮ y pulsa "Instalar aplicación" o "Añadir a pantalla de inicio".
  • iPhone (Safari): Presiona el botón Compartir ⎋ y selecciona "Añadir a pantalla de inicio".
Bot de Telegram (Alertas Push al Celular)

Recibe notificaciones automáticas cada vez que el escáner descubra nuevas oportunidades afines a NIKADU IA o CERABELA.

Parámetros del Escáner Autónomo

• Frecuencia: Cada 60 minutos (Expresión cron: 0 * * * *)
• SECOP II: Socrata Open Data API (SODA) — Dataset p6dx-8zbt
• Fondo Emprender: Extractor automatizado de convocatorias activas (SENA)
• Perfiles: NIKADU IA (Deep Tech / IA / Automatización) & CERABELA (Velas / Artesanías)
• Persistencia: Base de datos SQLite nativa con control de duplicados
